# Class demo data

This is an unchanged copy of the lecture's prepared CPSC NEISS 2025 dataset: 6,212 unweighted cases for ages 5–17. Source: https://www.cpsc.gov/Research--Statistics/NEISS-Injury-Data

The existing additional_care field has 525 True cases, including admission, transfer, observation, and three fatalities. False does not establish a mild outcome. These cases do not estimate national totals or risk per rider. Preparation excluded 97 overlapping-device records. Powered scooter is not exclusively electric.

Keep this copy inside the app folder so Render can access it independently of the lecture folders.
